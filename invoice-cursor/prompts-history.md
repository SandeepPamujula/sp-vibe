## How to Use

1. **To view prompts for a specific milestone**: Open the corresponding `prompts-history-milestone-N.md` file
2. **To add a new milestone**: Create a new file `prompts-history-milestone-N.md` and add a link to it in this index
3. **To update prompt history**: Follow the format specified in `.cursorrules` and update the appropriate milestone file

- Prompt numbers are sequential across all milestones
